DROP YOUR VIDEO FILES HERE
==========================

This folder holds every video used on the site:
 - Hover-preview videos on project cards (optional)
 - Hero videos shown inside the project modal (optional)

RECOMMENDED FILE NAMES
----------------------
  Card-hover videos   →  aurora-vessel-hover.mp4
                         (short loop, 4–6 seconds, no audio needed)

  Project-modal videos →  aurora-vessel.mp4
                          monolith.mp4
                          field-recordings.mp4

FILE FORMAT
-----------
.mp4 (H.264) — works everywhere.
.webm is also supported.

SIZE TIP
--------
Aim for under 10 MB per file so the page stays fast.
1080p is plenty; 720p is great for hover previews.

DON'T HAVE A VIDEO?
-------------------
That's fine — videos are completely optional.
In index.html, find the <video> tag for the project and delete it.

YOUTUBE / VIMEO INSTEAD?
------------------------
You don't need to upload anything here. In index.html, use the
<div class="d-embed"> block with an iframe (see the Monolith and
Echo example projects).
