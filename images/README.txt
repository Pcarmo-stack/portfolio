DROP YOUR IMAGE FILES HERE
==========================

This folder holds every image used on the site:
 - Project thumbnails
 - Gallery images
 - Your portrait photo (optional)

Recommended file names (just so you don't have to invent new ones):

  Project thumbnails  →  aurora-vessel-thumb.jpg
                         monolith-thumb.jpg
                         echo-thumb.jpg
                         field-thumb.jpg

  Gallery images      →  aurora-vessel-01.jpg
                         aurora-vessel-02.jpg
                         aurora-vessel-03.jpg
                         (use any numbering you like — the filenames just
                          need to match what's written in index.html)

  Portrait            →  portrait.jpg

RECOMMENDED SIZES
-----------------
Thumbnails  :  1200 × 1500 px (portrait works best)
Gallery     :  2000 px wide is plenty
Portrait    :  1200 × 1500 px

FILE FORMATS
------------
Use .jpg or .webp for photos.
Use .png only when you need transparency.
Keep each file under 500 KB if you can — your site will load faster.

REPLACING AN IMAGE
------------------
Simply drop a new file in here with the SAME filename — the site will pick
it up automatically. If you change the filename, also update its path
inside index.html (search for the old name and replace it).
